# 物理-机械能 · 知识点图谱

> 教练内部用。编号在笔记、错题、考点页之间共用，**不要改编号**。
> 每个点六行：内涵 / 前置 / 易混 / 考法 / 卡点 / 错了说明什么。

## PH-E1 功与功率

- **一句话**：W=Fscosθ；功率 P=Fv（v 沿力方向）
- **前置**：无
- **易混**：PH-E2
- **典型考法**：求功、求功率
- **常见卡点**：位移与力方向夹角取错
- **这个点错了多半是**：计算执行

## PH-E2 动能定理

- **一句话**：合外力做的总功 = 动能变化——只关心初末状态
- **前置**：PH-E1
- **易混**：PH-E3（守恒有前提，定理没有）
- **典型考法**：求速度、求摩擦做功、多过程问题
- **常见卡点**：漏掉某个力的功
- **这个点错了多半是**：**最高频**：习惯缺失

## PH-E3 机械能守恒

- **一句话**：只有重力/弹力做功时才守恒
- **前置**：PH-E2
- **易混**：PH-E2
- **典型考法**：求速度、判断是否守恒
- **常见卡点**：有摩擦还硬用守恒
- **这个点错了多半是**：概念没懂

## 关系

- PH-E1 → PH-E2 → PH-E3（功→定理→守恒，层层加前提）
