# 数学-数列 · 知识点图谱

> 教练内部用。编号在笔记、错题、考点页之间共用，**不要改编号**。
> 每个点六行：内涵 / 前置 / 易混 / 考法 / 卡点 / 错了说明什么。

## SN-01 等差数列基本量

- **一句话**：aₙ=a₁+(n−1)d；五个量（a₁,d,n,aₙ,Sₙ）知三求二
- **前置**：无
- **易混**：SN-04 等比数列（公差/公比语义相反）
- **典型考法**：求通项、求指定项、判断单调性
- **常见卡点**：把「第 n 项」写成「前 n 项和」
- **这个点错了多半是**：记忆缺失（公式写不出）

## SN-02 等比数列基本量

- **一句话**：aₙ=a₁·q^(n−1)；必须讨论 q=1 与 q≠1
- **前置**：SN-01 的思维框架
- **易混**：SN-01（等差是加，等比是乘，混淆最致命）
- **典型考法**：求通项、求公比、判断增减
- **常见卡点**：q=1 没有单独讨论
- **这个点错了多半是**：审题偏差或知识缺口

## SN-03 aₙ 与 Sₙ 互化

- **一句话**：见 Sₙ 就写 aₙ=Sₙ−Sₙ₋₁（n≥2），再单独验 n=1
- **前置**：SN-01 / SN-02
- **易混**：SN-05 递推构造（一个是互化，一个是造新关系）
- **典型考法**：给 Sₙ 求 aₙ、给递推式求通项
- **常见卡点**：n=1 边界没单独验
- **这个点错了多半是**：**最高频**：知道方法但忘了边界=习惯缺失；不知道要验=知识缺口

## SN-04 数列求和四法

- **一句话**：公式法、错位相减、裂项相消、分组求和——先判断通项是什么形状
- **前置**：SN-01 / SN-02 / SN-03
- **易混**：SN-03（互化是求通项，求和是求 Sₙ）
- **典型考法**：求前 n 项和、证明不等式
- **常见卡点**：选错方法（等差×等比没想起错位相减）
- **这个点错了多半是**：方法选择问题

## SN-05 递推构造

- **一句话**：把 aₙ₊₁=paₙ+q 这类式子构造成等比（加常数或除 p^n）
- **前置**：SN-02
- **易混**：SN-03（互化是消元，构造是变形）
- **典型考法**：证明数列是等比、求通项
- **常见卡点**：看不出要构造什么
- **这个点错了多半是**：方法选择问题，不是计算

## SN-06 新定义数列

- **一句话**：先用自己的话复述定义 → 编具体例子验证 → 再判断
- **前置**：整个数列章
- **易混**：无
- **典型考法**：判断某序列是否属于新定义、证明性质
- **常见卡点**：直接开始算，不从定义出发
- **这个点错了多半是**：★ 认知策略缺失（不是知识问题）

## 关系

- SN-01 → SN-03 → SN-04（通项是求和的前提）
- SN-02 ⇄ SN-01（加与乘，最易混）
- SN-05 → SN-02（构造完要当等比处理）
