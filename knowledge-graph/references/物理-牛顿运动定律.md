# 物理-牛顿运动定律 · 知识点图谱

> 教练内部用。编号在笔记、错题、考点页之间共用，**不要改编号**。
> 每个点六行：内涵 / 前置 / 易混 / 考法 / 卡点 / 错了说明什么。

## PH-N1 受力分析

- **一句话**：先重力、再接触力（弹力/摩擦）、再其他场力；每个力找施力物体
- **前置**：无
- **易混**：PH-N2
- **典型考法**：所有动力学题的第一步
- **常见卡点**：漏力或凭空多出力
- **这个点错了多半是**：**最高频**：习惯缺失

## PH-N2 牛顿第二定律

- **一句话**：F合=ma，合力与加速度同向
- **前置**：PH-N1
- **易混**：PH-C2 向心力（圆周里也用它，但方向特殊）
- **典型考法**：求加速度、求力
- **常见卡点**：加速度方向与合力搞反
- **这个点错了多半是**：概念没懂

## PH-N3 整体法与隔离法

- **一句话**：整体看外力，隔离看内力
- **前置**：PH-N1 / PH-N2
- **易混**：无
- **典型考法**：连接体、多物体系统
- **常见卡点**：整体法中把内力也算进去
- **这个点错了多半是**：方法选择

## 关系

- PH-N1 → PH-N2 → PH-N3（受力是根，定律是干）
- PH-N2 → PH-C2（圆周里用同一套，但方向特殊）
- PH-N2 → PH-E2（动能定理是能量视角的同一件事）
