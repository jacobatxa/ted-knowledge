# 物理-恒定电流 · 知识点图谱

> 教练内部用。编号在笔记、错题、考点页之间共用，**不要改编号**。
> 每个点六行：内涵 / 前置 / 易混 / 考法 / 卡点 / 错了说明什么。

## PH-I1 闭合电路欧姆定律

- **一句话**：E=U+Ir；U 是路端电压，不是电源电动势
- **前置**：无
- **易混**：PH-I2
- **典型考法**：求电流、电压、功率
- **常见卡点**：把 U 当成电动势
- **这个点错了多半是**：概念没懂

## PH-I2 电路动态分析

- **一句话**：先判断总电阻变化 → 总电流 → 分支
- **前置**：PH-I1
- **易混**：PH-I3
- **典型考法**：滑片移动、开关通断
- **常见卡点**：局部看局部，不先看总电阻
- **这个点错了多半是**：方法选择

## PH-I3 电表内阻的影响

- **一句话**：电压表分流、电流表分压；测 E、r 时两者都会造成系统误差
- **前置**：PH-I1
- **易混**：无
- **典型考法**：误差分析、图线截距斜率含义
- **常见卡点**：忽略电表内阻直接算
- **这个点错了多半是**：★ 知识缺口（很多人从没意识到）

## 关系

- PH-I1 → PH-I2（动态分析建立在闭合电路上）
- PH-I1 → PH-I3（误差分析要知道每个量是谁的）
