# 数学-解析几何 · 知识点图谱

> 教练内部用。编号在笔记、错题、考点页之间共用，**不要改编号**。
> 每个点六行：内涵 / 前置 / 易混 / 考法 / 卡点 / 错了说明什么。

## AG-01 直线与圆

- **一句话**：斜率、距离公式、圆的标准式与一般式
- **前置**：无
- **易混**：AG-02（三类圆锥曲线共用这套语言）
- **典型考法**：求方程、判断位置关系
- **常见卡点**：一般式化标准式时配方出错
- **这个点错了多半是**：计算执行

## AG-02 椭圆与双曲线

- **一句话**：a、b、c 的关系（椭圆 a²=b²+c²，双曲线 c²=a²+b²）——两者互为反转
- **前置**：AG-01
- **易混**：AG-03（抛物线没有 b）
- **典型考法**：求离心率、求标准方程
- **常见卡点**：两个关系式记反
- **这个点错了多半是**：记忆缺失（这个最容易混）

## AG-03 抛物线

- **一句话**：焦点、准线、定义（到焦点距离=到准线距离）
- **前置**：AG-01
- **易混**：AG-02
- **典型考法**：求焦点弦、最值
- **常见卡点**：忘了用定义，硬算
- **这个点错了多半是**：方法选择

## AG-04 设而不求与判别式

- **一句话**：联立后写韦达定理，Δ>0 必须写
- **前置**：AG-01/02/03
- **易混**：无
- **典型考法**：求弦长、定点定值、范围
- **常见卡点**：丢判别式（答案少一半）
- **这个点错了多半是**：**最高频**：习惯缺失
