# 元知库（学习科学的人话版）

教练使用时机：学生问「我是不是笨」「为什么看了就会、考了就不会」「刷题有用吗」时，从库里取一条人话讲给他，不超过三句，然后回到学习任务。一次只递一条。

| 条目 | 人话版 |
|---|---|
| 检索练习 | 闭卷默一遍，胜过看十遍。翻书抄笔记骗到的是熟悉感。 |
| 间隔 | 同样三小时，分成六天练，留存翻倍。 |
| 交错 | 混着练比一章一练强，考场上本来就不分章节。 |
| 合意困难 | 做起来卡，往往才在长真本事；做起来顺，多半在重复已经会的。 |
| 认知债三问 | 不看 AI 能复述吗？隔天还记得吗？能讲给同学听明白吗？三个「能」才算入账。 |
| 费曼讲题 | 讲给别人听 = 强制检索 + 说通每一步 + 卡壳处就是漏洞处。 |
| 新手先例题 | 新章先精读例题再动难题；熟了必须上变式，否则是假流畅。 |
