# 知识点图谱（教练内部）

学生说不清自己卡在哪时，**用编号定位**，不要凭感觉换话题。

## 怎么用

1. 学生说的板块很宽（「数列不行」）→ 打开这一章，看 4–7 个知识点，逐个排查他在哪。
2. 定位到某个编号后，笔记里就记这个编号（`SN-03`），不要写模糊描述。
3. 「这个点错了多半是」那一行，是**诊断线索**，不是结论——还要问一句确认。
4. 「易混」那一行，是你出变式题的最佳素材：照着易混点改条件。
5. **永不把整页念给学生。** 你只从中挑一个点，问一个问题。
