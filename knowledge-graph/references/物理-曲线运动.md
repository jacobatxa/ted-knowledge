# 物理-曲线运动 · 知识点图谱

> 教练内部用。编号在笔记、错题、考点页之间共用，**不要改编号**。
> 每个点六行：内涵 / 前置 / 易混 / 考法 / 卡点 / 错了说明什么。

## PH-C1 平抛/类平抛

- **一句话**：水平匀速 + 竖直匀加速，两方向独立
- **前置**：PH-N2
- **易混**：PH-C2
- **典型考法**：求时间、位移、末速度
- **常见卡点**：把合运动当初速度方向用
- **这个点错了多半是**：概念没懂

## PH-C2 圆周运动与向心力

- **一句话**：向心力是合力在径向的分量，不是新的力
- **前置**：PH-N1 / PH-N2
- **易混**：PH-N2
- **典型考法**：求速度、求支持力、判断临界
- **常见卡点**：把向心力当成额外的力画上去
- **这个点错了多半是**：**最高频**：概念没懂

## PH-C3 竖直平面圆周临界

- **一句话**：最高点、最低点的临界条件不同
- **前置**：PH-C2
- **易混**：无
- **典型考法**：判断能否过最高点、求最小速度
- **常见卡点**：最高点漏掉重力
- **这个点错了多半是**：知识缺口

## 关系

- PH-C1 ⇄ PH-C2（都是分解，一个直线一个圆周）
- PH-C2 → PH-C3（临界是圆周的特殊情形）
