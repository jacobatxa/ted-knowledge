# 化学-水溶液离子平衡 · 知识点图谱

> 教练内部用。编号在笔记、错题、考点页之间共用，**不要改编号**。
> 每个点六行：内涵 / 前置 / 易混 / 考法 / 卡点 / 错了说明什么。

## CH-01 弱电解质的电离

- **一句话**：部分电离、存在平衡；Ka/Kb 越大酸性/碱性越强
- **前置**：无
- **易混**：CH-02 水解（电离是电离，水解是水解，两者常同时存在）
- **典型考法**：比较酸性强弱、判断离子浓度
- **常见卡点**：把强电解质当弱电解质、忽略电离度
- **这个点错了多半是**：知识缺口

## CH-02 盐类水解的判断

- **一句话**：只有弱酸根、弱碱阳离子水解；生成弱电解质才是水解
- **前置**：CH-01
- **易混**：CH-01
- **典型考法**：判断哪些离子水解、写水解方程式
- **常见卡点**：以为带电荷就水解；把强酸强碱的离子也写进去
- **这个点错了多半是**：**最高频**：概念没懂

## CH-03 越弱越水解

- **一句话**：对应酸/碱越弱，其离子水解越强；碱性/酸性随之上来
- **前置**：CH-02
- **易混**：CH-01（电离常数与水解程度是倒数关系）
- **典型考法**：比较同浓度盐溶液的 pH
- **常见卡点**：只看离子电荷或分子量，不看对应酸碱强弱
- **这个点错了多半是**：方法选择

## CH-04 三大守恒

- **一句话**：电荷守恒、物料守恒、质子守恒；写等式先列全物种
- **前置**：CH-01 / CH-02
- **易混**：无
- **典型考法**：离子浓度大小比较、等式判断
- **常见卡点**：漏掉 H⁺/OH⁻ 项，或漏掉未电离的分子
- **这个点错了多半是**：**最高频**：习惯缺失

## 关系

- CH-01 ⇄ CH-02（电离与水解，最易混）
- CH-02 → CH-03（先判断会不会水解，再比强弱）
- CH-02 → CH-04（守恒式里要写全所有物种）
