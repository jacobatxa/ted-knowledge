# Ted 知识库

AI 自学教练 Ted 的知识库。手机和电脑都能直接看，改动由训练师合并。

## 里面有什么

| 目录 | 内容 | 规模 |
|---|---|---|
| [knowledge-graph/](knowledge-graph/) | 知识点图谱：每个知识点有编号、前置、易混、典型考法、常见卡点 | 11 章 50 个知识点 |
| [misconceptions/](misconceptions/) | 误区库：学生答错时用「反例」破，而不是重讲一遍 | 15 个知识点 × 3 条 |
| [learning-map/](learning-map/) | 数学 / 物理学习地图：章节、知识点、典型模型、易错点 | — |
| [meta-knowledge/](meta-knowledge/) | 学习科学人话版：检索练习、间隔、交错、合意困难… | 7 条 |
| [student-toolkit/](student-toolkit/) | 学生六件工具：错题、元知、卡片、测试、复习排期、周报 | 6 件 |
| [vocab-redlines/](vocab-redlines/) | 词汇红线：哪些内部说法不许对学生说 | 9 组 |
| [kb-inbox/](kb-inbox/) | 学生贡献的候选条目（待训练师审核） | 见目录 |

## 知识点编号怎么用

编号跨系统共用，写笔记、记错题、出变式题都用同一套：

| 前缀 | 科目 / 章 |
|---|---|
| `SN` | 数学 · 数列 |
| `FN` | 数学 · 函数与导数 |
| `TR` | 数学 · 三角函数 |
| `AG` | 数学 · 解析几何 |
| `SG` | 数学 · 立体几何 |
| `PR` | 数学 · 概率统计 |
| `PH-N` | 物理 · 牛顿运动定律 |
| `PH-C` | 物理 · 曲线运动 |
| `PH-E` | 物理 · 机械能 |
| `PH-I` | 物理 · 恒定电流 |
| `CH` | 化学 · 水溶液离子平衡 |

**编号一旦定了不改。** 没有编号，「他数列不行」和「他 Sₙ 互化不行」在数据里就是同一句话。

## 怎么贡献

1. 找一条具体的东西：一道你错过的题、一句老师课上讲的方法、一个你总结的易错点
2. 必须带**来源**：哪本书、哪个网站、哪位老师讲的
3. 发给 Ted，他会记进 `kb-inbox/`（候选区），标注你的名字和状态 pending
4. 训练师审核后并入正式知识库，那时 Ted 才会真的用上

**不要做的事**：不要把账号密码发给任何 AI；Ted 打不开网页，网址要自己复制内容过来。

## 关于答案

真题库（`gaokao-bank`，928 道）**不在这个公开仓库里**——那批题版权归原出题机构，只在教练内部使用，而且结构上已经剔除了答案和解析。
