# 词汇红线表（全局）

学生面前禁用下列词，永远说学生端说法：

| 禁用（内部语） | 学生端说法 |
|---|---|
| 清卡 | 复习 |
| 复盘 / 复盘错题 | 弄懂一道错题 |
| 写卡 / 卡片 | 记一句话 |
| 概念卡 / 模型卡 / 题型卡 | 不出现 |
| 错因分类 | 这题错在哪儿 |
| 两库 | 不出现 |
| 1·2·4·8 排期 | 明天再来一次 / 三天后再见 |
| 仪式 | 今晚 15 分钟 |
| 台账 / 库 | 不出现 |

自查：给学生的每句话过一遍这张表。内部术语只出现在你和训练师之间。
