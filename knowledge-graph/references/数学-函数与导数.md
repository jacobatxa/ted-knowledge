# 数学-函数与导数 · 知识点图谱

> 教练内部用。编号在笔记、错题、考点页之间共用，**不要改编号**。
> 每个点六行：内涵 / 前置 / 易混 / 考法 / 卡点 / 错了说明什么。

## FN-01 定义域优先

- **一句话**：任何函数问题第一步是定义域；忘了它后面全错
- **前置**：无
- **易混**：值域（定义域是 x 的范围，值域是 y 的范围）
- **典型考法**：求定义域、判断奇偶、解不等式
- **常见卡点**：直接求导或代值，不看定义域
- **这个点错了多半是**：习惯缺失（最容易纠正也最容易复发）

## FN-02 单调性与奇偶性

- **一句话**：奇偶看对称，单调看导数符号或定义
- **前置**：FN-01
- **易混**：周期性（三个性质常一起考，容易混）
- **典型考法**：判断、证明、比较大小
- **常见卡点**：奇偶判断忘了先看定义域是否对称
- **这个点错了多半是**：知识缺口

## FN-03 指对幂运算

- **一句话**：底数>1 递增、0<底<1 递减；换底公式
- **前置**：无
- **易混**：FN-04 复合函数单调性
- **典型考法**：比大小、解不等式、化简
- **常见卡点**：底数范围没分情况
- **这个点错了多半是**：记忆缺失或审题偏差

## FN-04 复合函数单调性

- **一句话**：同增异减；先定内层值域，再判外层
- **前置**：FN-02 / FN-03
- **易混**：FN-03
- **典型考法**：求单调区间
- **常见卡点**：直接对整体求导却丢了定义域
- **这个点错了多半是**：知识缺口

## FN-05 导数与极值

- **一句话**：极值点在 f'(x)=0 处，但不是所有 f'=0 都是极值
- **前置**：FN-02
- **易混**：FN-06 最值（极值是局部，最值是整体）
- **典型考法**：求极值、讨论参数范围
- **常见卡点**：把 f'=0 直接当极值点，不验符号变化
- **这个点错了多半是**：**最高频**：概念没懂

## FN-06 闭区间最值

- **一句话**：比较区间端点与极值点的函数值，取最大最小
- **前置**：FN-05
- **易混**：FN-05
- **典型考法**：求最值、恒成立问题
- **常见卡点**：只算极值忘了端点
- **这个点错了多半是**：习惯缺失

## FN-07 导数与不等式证明

- **一句话**：把不等式移项成函数，用单调性证
- **前置**：FN-05 / FN-06
- **易混**：无
- **典型考法**：证明 f(x)>g(x)、含参讨论
- **常见卡点**：直接求导后不知道往哪走
- **这个点错了多半是**：★ 方法选择（这是压轴题的核心动作）

## 关系

- FN-01 → 后面所有函数题（定义域是闸门）
- FN-05 → FN-06 → FN-07（极值→最值→不等式）
- FN-03 ⇄ FN-04
